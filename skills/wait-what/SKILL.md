# Re-explain with missing context

Identify the missing premise, unfamiliar term, or reasoning jump in the last explanation. Restate the main point in the user's language, introduce the necessary context, and use one concrete example if it helps.

Use the project's glossary where it clarifies terms, explaining those terms on first use. Reduce jargon and do not require a formal English standard for a non-English conversation. Preserve the original question and any active task.

Finish when the user can see what the point means and why it matters. Do not create files or launch another workflow for a re-explanation alone.
