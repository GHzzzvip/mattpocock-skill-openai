# Coordinate a sustained effort

Establish the objective, completion criteria, constraints, and available budget from the user. Track work and evidence in a small durable progress artifact using the workspace's convention. Distinguish blocked tasks from tasks ready to proceed.

Delegate independent work only when the host supports it and delegation is authorized. Give bounded ownership and artifact pointers; keep dependent integration sequential. Otherwise work directly. Avoid turning ordinary tasks into a permanent background operation.

Improve the working environment only when it directly supports the requested objective. Report larger improvement opportunities rather than silently expanding scope. Create schedules, reminders, or external notifications only when requested and supported by actual tools.

Continue until the requested objective is met, an explicit limit is reached, or a dependency prevents progress. Keep the user informed of material findings and changes. A handoff must include the last verified state and next useful action; do not promise execution after the session ends unless a real runner has been configured.
