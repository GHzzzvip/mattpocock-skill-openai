# Session boundaries

Continue in the current session when the next step needs the original reasoning and there is adequate room. Do not move context merely to follow a workflow diagram.

Start a fresh context when the old discussion is irrelevant and the next task is self-contained. Use the host's actual session controls; command names vary.

Write a handoff when moving between directories, hosts, collaborators, or a separate side task. Include decisions and references that would otherwise be lost.

Use a subagent only for a bounded independent task when the host and instructions allow it. Do not assume background work persists after a session ends.

Compact at a natural boundary when retained context is relevant but too large. Keep the user goal, constraints, decisions, evidence pointers, and next steps. A summary is lossy; preserve the original artifact when a later decision needs it.

No fixed token count guarantees reasoning quality. Use actual context pressure and task structure rather than the upstream estimate of a universal smart zone.
