# Clarify a decision

Identify the desired outcome, known constraints, and decisions still open. Inspect available evidence yourself; ask the user for preferences or facts you cannot obtain.

Treat dependent decisions as a tree. Ask a manageable batch whose prerequisites are settled, with a recommendation and its tradeoff for each question. Defer downstream questions until their prerequisites are answered. Use the host's question tool if available, otherwise plain conversation.

Reuse answers already given. Challenge contradictions with concrete scenarios. A brief acceptance can adopt a clearly stated recommendation, but silence is not a decision. Match the depth of questioning to the user's requested interview and stop when material uncertainties are settled or explicitly deferred.

Finish with the agreed outcome, constraints, decisions, and remaining assumptions. An interview request alone does not authorize implementation. Continue into implementation when the user has already requested that broader task.
