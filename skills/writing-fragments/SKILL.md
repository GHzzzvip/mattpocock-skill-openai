# Collect fragments

Use the requested raw-material file; ask for a destination only if it is unresolved. Capture useful material from the initial prompt as well as later discussion. Explore experiences, examples, claims, analogies, and promising phrases without forcing an outline.

Start a new file with a working H1 title. Separate fragments with horizontal rules and preserve their order of arrival. Fragments can contain prose, quotes, lists, or code; they need to be useful to the author rather than self-contained for a new reader.

Re-read before every write and append without overwriting user edits. Edit, merge, or remove specific fragments when requested. Do not invent personal experiences or attribute generated wording as a real quotation.

Keep conversation moving; saving each fragment is part of the requested workflow and does not require a separate permission dialog. Stop when the user is done exploring, then report the file and potential next step. Article shaping is a separate task.
