# Discuss a plan

Use the available `grilling` skill when present. Otherwise identify the outcome, inspect obtainable facts, and ask focused questions with recommendations, resolving prerequisites before dependent decisions.

Keep this workflow conversational. Stress-test the user's choices with concrete scenarios, reuse prior answers, and conclude with the agreed plan and unresolved points. Save documents only if requested. If the user wants terminology and decisions recorded in a repository, suggest `grill-with-docs`.
