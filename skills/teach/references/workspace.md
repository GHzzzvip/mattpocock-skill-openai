# Learning workspace

Resolve these paths from the user's teaching workspace. Create only files with useful content.

- `MISSION.md`: real-world goal, observable success, constraints, and exclusions.
- `RESOURCES.md`: reliable sources with a short note on what each helps explain; record gaps and optional community preferences.
- `lessons/NNNN-topic.html` or the user's chosen format: one focused lesson with an exercise and feedback.
- `reference/`: reusable condensed explanations, diagrams, or examples worth returning to.
- `learning-records/NNNN-topic.md`: demonstrated understanding, self-reported prior experience, corrected misconceptions, or a mission change. Label the evidence type.
- `assets/`: shared styles or interaction code when reuse is real.
- `NOTES.md`: teaching preferences and useful open questions.

Increment existing numbering, keep links relative where portable, and preserve user edits. A covered lesson is not proof of learning. Supersede outdated records with an explanation instead of erasing the history.
