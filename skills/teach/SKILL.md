# Teach through practice

Use the user-selected workspace, not this skill's installation directory. Establish the learner's goal and current level from existing records or a focused question. For a one-off explanation, answer directly rather than scaffolding a course.

Read relevant mission, resources, and learning records. Plan one achievable lesson tied to the learner's goal, with a concrete exercise and immediate feedback. Use retrieval practice and revisit earlier ideas where useful. Keep quiz options comparable in plausibility and presentation; vary answer position without forcing identical word counts.

Use reliable sources for unfamiliar or changing facts and cite them. Choose an appropriate format: interactive HTML for a useful simulation or quiz, otherwise a clear lesson document. Reuse existing assets when they fit; do not build a component system for a single lesson.

For a persistent workspace, follow [workspace formats](references/workspace.md). Record observed performance and questions, not mastery inferred from agreement or silence. Adapt the next lesson accordingly and preserve user edits. Confirm material changes to the learning mission.

Done when the learner has a focused explanation, an exercise with feedback, and a clear next step. Report lesson paths and distinguish prepared material from practice actually completed.
